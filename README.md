# 數字聽力練習

> Números en Chino: Escucha · 聽中文念出數字，輸入你聽到的數字（每回合 1 分鐘）

- **難度：** 0–9999（預設）、10000–99999、0–99999 混合；選擇會記在瀏覽器
- **設定：** ⚙️ 可選繁／簡體、介面語言（西文／英文／只有中文）、拼音／注音、語速
- **網址：** https://wangchiapin.github.io/numeros/
- **Firebase 專案：** 排行榜不使用；2026-10-21 起只把遊玩紀錄（訪客、開始、玩完）寫到 memorma-24dab 的 `plays`、`visits`
- **登入方式：** 匿名登入（只為了寫遊玩紀錄）
- **狀態：** 使用中

## 玩法
1. 按開始，電腦或手機用台灣中文念出一個數字（可按「再聽一次」）。
2. 在輸入欄打出你聽到的阿拉伯數字，送出後按「下一題」。
3. 每回合 1 分鐘（程式裡 `SESSION_SECONDS = 60`），時間到看結果；答錯時畫面會顯示正確數字、中文念法和拼音／注音，結果頁會列出所有錯題。
- 沒有排行榜，也沒有兩人模式。
- 讀音一律台灣讀音；「一」會變調（接萬念 yí、接百／千念 yì、接十或在最後念 yī），其他字照本調。
